# Changelog

## 0.2.2 — distribution cleanup

Removed consumer-specific profiles and adapter recipes. Generalized inherited examples and runtime notes; kept consumer contracts outside the portable package.

## 0.2.1 — open-source early release

MIT license for first-party code, documentation and bundled examples after owner confirmation. Updated provenance, packaged notices and distribution metadata. Added an explicit comparison with a plain Blender agent, a reproducible repair demonstration, a fair benchmark protocol and an adoption-first roadmap. No comparative performance or autonomous modelling claims.

## 0.2.0 — standalone private preview

Portable core/schema v2, five original procedural starters, configurable profiles, source/export surface checks, pose relations, wrapped patches, host-normal frames, RGBA masks, generic skeletal export, actual-GLB region rendering, offline viewer, optional reference-completion provider/ledger, content cache, checksummed bundles, source releases, documentation, agent skill and regressions.

Game-specific staging/art remain in the game. Licensing was pending at this preview and resolved in 0.2.1.
